# Fire Alarm Alert System

An IoT-based fire and smoke detection project built using Raspberry Pi, sensors, and MicroPython.

## Project Overview

This project is designed to detect fire or smoke conditions and provide an alert using an IoT-based setup.

## Technologies Used

- Raspberry Pi
- MicroPython
- IoT
- Sensors

## Project Files

- `main.py` — Main program code
- `diagram.json` — Project circuit/setup diagram

## Purpose

The project demonstrates the practical use of sensors, Raspberry Pi, and MicroPython for a basic fire and smoke alert system.

## Project Type

Academic / IoT Project
